# 公共头文件说明

本候选包直接取自开发源 v1.369.6 的公共头文件，未冒用 v1.369.8 版本号。它不是与客户 v1.369.7 包的接口差异报告。

- `basedef.h` 的 GNU 分支将 BYTE/WORD/DWORD/UCHAR/USHORT/UINT/ULONG 七个 typedef 置于 `#if 0`；标准整数类型来自 stdint.h。不能假设该头单独提供这些兼容名称，也不能盲目重复定义它们。
- `platforms.h` 定义 `__TXW82X__`，选择 `plat_txw82x.h`；这是 TXW82x 专用交付，不作为跨平台通用头包。
- `plat_txw82x.h` 依赖所选 SDK/系统的类型与接口，必须在客户实际工具链验证。
- SDK 侧 `mp4_key_msg` 在可选聚合写优化中增加字段；所有使用该结构体的源码必须一致构建。
- 新增 demux 控制枚举在原有枚举末尾追加，与实现一起采用。
- `pin_param.h` 未改动，保留原厂被跟踪版本。

待验证：C/C++（若客户需要）独立包含、与 FatFS/平台头两种包含顺序、对外结构体大小/对齐/偏移及声明与库 ABI 一致性。未做这些测试前不得标注“头文件兼容已通过”。
